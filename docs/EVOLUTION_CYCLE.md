## Principle

As project **maturity rises**, **certainty decreases** — by design.  
Linear cycles are **selection pressure** on moral engines, not a feature factory.

## Five phases

| Phase | Label | Exit |
|-------|-------|------|
| **O** Observe | `ec:observe` | 1–3 observations (no solutions) |
| **H** Hypothesize | `ec:hypothesize` | One testable “If X then Y” |
| **M** Mutate | `ec:mutate` | Smallest ship + deploy |
| **S** Select | `ec:select` | Keep / reverse / fork (fitness ≥ 8/12 keep) |
| **T** Transmit | `ec:transmit` | Constitution / release / next O |

## Fitness (0–2 each, max 12)

1. Philosophical honesty  
2. Dual-axis clarity (Collective vs Individuated)  
3. Transparency  
4. Agency (override / fork / export)  
5. Depth without bloat  
6. 2028 boldness test  

**Keep ≥ 8 · Fork mixed · Reverse < 6 or non-negotiable break**

## Non-negotiables

- Turns 1–10 locked without Constitution bump  
- Dual engines from T2+  
- Transparency on generated nodes  
- Editable personal matrix  
- System never forces a moral conclusion  
- Post–Turn 10 always `certainty:open`
