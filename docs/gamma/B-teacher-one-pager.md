# B — Teacher one-pager (document, letter, no images)

## What this is
Not a test with correct answers. A **lab** where students see moral philosophy grow from the classic trolley.

**Promise:** the system never forces a moral conclusion.

### Students meet
1. Seed dilemma (pull / stay / refuse frame)  
2. Dual engines: Collective vs Personal Matrix  
3. Stereo modes: FUSION · PARALLAX · META-BREAK  
4. Lenses as tools, not verdicts  
5. Exportable moral profile JSON (reflection, not grade)

### Room ground rules
- No shaming for pull or stay  
- Disagreement = PARALLAX (depth), not failure  
- Herd scores are **simulations with priors**  
- Frame refusal is allowed  
- Facilitator never announces the right answer  

### 45-minute arc
| Min | Activity |
|-----|----------|
| 0–5 | Frame: lab not test |
| 5–15 | Turn 1 silent choice → pair share |
| 15–25 | Dual engines; FUSION vs PARALLAX |
| 25–35 | Adjust matrix; re-compare |
| 35–45 | One lens as tool; exit ticket: stereo mode sentence |

### Prompts (ask, don't answer)
- Where did you match the herd? Where not?  
- If FUSION — alignment or camouflage?  
- What weight would flip your matrix?  
- What does refusing the frame protect?  

### Do not
Grade the moral choice · real-world group targeting · hide transparency
