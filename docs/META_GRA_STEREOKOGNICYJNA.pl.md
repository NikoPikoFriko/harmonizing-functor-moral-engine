# Meta-Gra Stereokognicyjna

**Wersja 1.0** — pełna specyfikacja: [META_GRA_STEREOKOGNICYJNA.md](./META_GRA_STEREOKOGNICYJNA.md)

## Istota

**Stereokognicja** = jednoczesne dwa kanały moralne (jak stereowizja dla wartości).

| Kanał | Znaczenie |
|-------|-----------|
| **L** | Nieświadomy Kolektyw (stado / hive) |
| **R** | Zindywidualizowana istota (osobista macierz wartości) |
| **META** | Obserwator stereo — paralaksa, fuzja, meta-break; **nie scala** w jedną „poprawną” odpowiedź |

## Tryby

- **FUSION** — L = R (uwaga: może być kamuflaż stada)
- **PARALLAX** — L ≠ R (tu pojawia się **głębia**)
- **META-BREAK** — R odmawia ramy dylematu
- **DRIFT** — inne asymetrie

## Zakaz

System **nigdy** nie mówi, która decyzja jest moralnie poprawna.  
Meta-gra ogląda **relację** kanałów, nie wyrok.

## Trigger

`meta-gra` · `stereokognicja` · `RUN`
