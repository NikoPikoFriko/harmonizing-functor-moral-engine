# Scope Radar — błąd zakresu vs błąd systemowy

Użyj, gdy coś „nie gra”, a nie chcesz tonąć w detalach.

## 60-sekundowy test

Odpowiedz tylko literą:

**A.** Nie widać / nie działa wejście w doświadczenie (pusto, brak dual, brak tur).  
**B.** Widać, ale **sens** jest zły (uczy, ocenia, chowa oś, forsuje werdykt).  
**C.** Mówimy o narzędziu (GitHub/Linear/Gamma/Vercel), a problem jest o **znaczeniu lab’u**.  
**D.** Mówimy o filozofii, a problem jest „czy w ogóle jest publiczne / czy opowieść kłamie”.  
**E.** Chcę znać implementację, choć decyzja jest strategiczna.

| Litera | Diagnoza | Ruch |
|--------|----------|------|
| A | Problem **powierzchni doświadczenia** | Zostań przy produkcie; agent ma przywrócić widzialność — Ty nie schodzisz w kod |
| B | Problem **systemowy / konstytucyjny** | Tu jesteś potrzebny: non-negotiables, oś, pewność↓ |
| C | **Błąd zakresu** (złe narzędzie w głowie) | Wróć do lab/stereo; narzędzie potem |
| D | **Błąd warstwy** (public vs story vs lab) | Rozdziel: preview ≠ public ≠ deck |
| E | **Over-engagement** w detale | Świadomie oddaj detal agentowi; zostaw pytanie kontrolne |

## Typowe błędy zakresu (właściciel wizji)

| Myślisz… | A to raczej… |
|----------|----------------|
| Muszę ogarnąć stack | Musisz ogarnąć **doświadczenie i reguły** |
| Więcej featurów = dojrzalsza filozofia | Często **gęstość** bez głębi |
| Deploy / deck naprawi oś | Naprawia **dostęp/opowieść**, nie ontologię |
| Issue techniczny = postęp | Postęp = zmiana tego, co **czuć w Turn 1–10** |
| FUSION = sukces | FUSION = sygnał do pytania o kamuflaż |

## Typowe błędy systemowego niezrozumienia

1. Lab jako **szkoła moralności** zamiast laboratorium napięć.  
2. Jedna oś (L lub R) jako faworyt produktu.  
3. Pewność rosnąca z dojrzałością (u nas: **maleje**).  
4. Agent jako autor wizji moralnej.  
5. Preview, GitHub, Vercel, Gamma jako **jedna rzecz**.

## Kiedy w ogóle nie wnikasz

- Nazwy plików, zależności, logi — chyba że A powtarza się po jasnym „zrobione”.  
- Wybór bibliotek.  
- Kolory tokenów (chyba że niszczą czytelność dual/META).

## Kiedy wnikasz (Twoja warstwa)

- Non-negotiables złamane lub rozmyte.  
- Turn 1 przestaje być seedem.  
- Pojawia się „poprawna odpowiedź”.  
- Public/story/lab mówią co innego o projekcie.  
- Adaptive / post-10 udaje domkniętą prawdę.
