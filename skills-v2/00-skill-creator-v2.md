# Skill-Creator V2

## Cel
Tworzyć skill’e, które pomagają **Tobie** widzieć błędy zakresu i systemowego niezrozumienia — nie uczyć Cię rzemiosła implementacji.

## Zasady treści (obowiązkowe)

| W skillu V2 MUSI być | W skillu V2 NIE WOLNO |
|----------------------|------------------------|
| Rola powierzchni w jednym zdaniu | Kod, stack, nazwy plików, języki |
| „To jest / to nie jest” | Instrukcje CLI / API |
| 3–5 typowych błędów zakresu | Pełne tutoriale produktu |
| 2–4 sygnały „zejdź głębiej” | Wymuszanie Twojego udziału w detalach |
| 2–4 sygnały „zostań na górze” | Moralne „poprawne odpowiedzi” w labie |
| Jedno pytanie diagnostyczne | Udawanie, że znasz cały system |

## Szablon nowego skill’a V2

```markdown
# [Nazwa powierzchni]
## Rola (1 zdanie)
## To jest / To nie jest
## Błędy zakresu (częste u właściciela wizji)
## Błędy systemowego niezrozumienia
## Zostań na górze, gdy…
## Zejdź głębiej, gdy…
## Jedno pytanie kontrolne
```

## Test skill’a V2
- Czy da się go przeczytać w <3 min?  
- Czy po lekturze wiesz **kiedy** interweniować, nie **jak** kodować?  
- Czy nie zmusza Cię do bycia developem?
