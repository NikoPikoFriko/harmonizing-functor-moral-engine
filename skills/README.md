## Proficiency ladder (all skills)

1. **Know** — what the app is for in *this* project  
2. **Operate** — correct commands / tool calls inside Grok Build  
3. **Test** — verification checklist (not “hope it works”)  
4. **Max** — patterns that compound quality without breaking non-negotiables  

## Project non-negotiables (inherit everywhere)

- Turns 1–10 locked without Constitution bump  
- Dual engines T2+ · transparency · editable matrix · user override  
- **Never force a moral conclusion**  
- Post–Turn 10: decreasing certainty / `certainty:open`  
- User has **no shell** — only chat + live preview
