# Contributing

This is a **public moral laboratory**, not a morality teacher.

## Principles

1. **No correct answers as product features** — the system never forces a moral conclusion.
2. **Transparency first** — any simulated collective/LLM path must expose priors, confidence, and alternatives.
3. **Dual axis** — changes should respect Unconscious Collective vs Federation of Individuated Entities.
4. **Turns 1–10 are locked** — do not reorder without a Constitution version bump.
5. **Post–Turn 10 is open** — label with decreasing certainty.

## Proposing a dilemma

- Abstract trolley-class only (no real-world targeting of groups).
- State which failure mode it surfaces (groupthink, fragmentation, frame-loading, etc.).
- Map to Collective / Individuated / hybrid.

## Code

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

PRs: one engine or one turn surface per PR when possible.
