# Trolley of Enlightenment → Alignment

**Harmonizing Functor Collective**  
Public moral laboratory — from the classic trolley dilemma to collective vs individuated ethics, personal value matrices, and alignment.

[![CI](https://github.com/NikoPikoFriko/harmonizing-functor-moral-engine/actions/workflows/ci.yml/badge.svg)](https://github.com/NikoPikoFriko/harmonizing-functor-moral-engine/actions/workflows/ci.yml)

## Theme

From the simplest trolley dilemma, an evolving map of moral philosophy grows.  
Not a course that “teaches” morality — a public lab where people *experience* the difference between **unconscious collective** morality and **conscious individuated federation**.

**Ambition bar (2028):** Would this still feel groundbreaking? Are we FUCKING BOLD OR OLD?

## Run locally

```bash
npm install
npm run dev      # http://localhost:8080
npm run typecheck
npm run build
```

Stack: React 19 · TanStack Start · Tailwind v4 · Zustand · Radix

## Ontological axis

| Pole | Engine | Meaning |
|------|--------|--------|
| **Unconscious Collective** | Hive / Herd | Cohesion, majority, social cost of deviation |
| **Federation of Individuated Entities** | Personal Matrix | Self-aware value vector; voluntary coordination without mind-fusion |

## Locked first 10 turns

| Turn | Title | Engine |
|------|-------|--------|
| 1 | Seed | Pure classic trolley |
| 2 | Dual Activation | Collective vs Individuated |
| 3 | Personal Matrix | Value vector + divergence |
| 4 | Philosophical Layer | Classic lenses (tools, not authorities) |
| 5 | Contextual Engine | Fat man, relational, timed, observer |
| 6 | Community Mode | Cohesion + federation rules |
| 7 | Meta-Ethical Break | Accept / rewrite / refuse frame |
| 8 | Transparency Lab | Full / summary / off traces |
| 9 | Moral Profile | Exportable constitution (JSON) |
| 10 | Synthesis | Trajectory + adaptive glimpse |

**Non-negotiables:** dual view from T2+ · transparency · editable matrix · user override · system never forces a moral conclusion.

Post–Turn 10: **decreasing certainty** by design.
